# TEN SECOND HERO

### A GMTK Game Jam 2026 Entry

---

## 🎮 About

**Ten Second Hero** is a fast-paced action game where time is your only resource. Defend a doorway from waves of enemies while a timer counts down from 10 seconds. Kill enemies to add time, protect the door, and survive across 3 escalating levels.

**Theme:** COUNT DOWN

---

## 🕹️ How to Play

| Action | Input |
|--------|-------|
| Move | WASD / Arrow Keys |
| Dash Attack | Space / Shift |

**Objective:**
- Kill enemies to add +2 seconds to the timer
- Protect the door (10 HP)
- Reach the timer target to unlock the door
- Complete all 3 levels to win

**Game Over Conditions:**
- Timer hits 0
- Door health hits 0

---

## 🛠️ Tech Stack

- **Engine:** Unity 2022 LTS (2D)
- **Language:** C#
- **Art:** Unity primitives + custom sprites
- **Audio:** Free SFX + custom generated sounds
